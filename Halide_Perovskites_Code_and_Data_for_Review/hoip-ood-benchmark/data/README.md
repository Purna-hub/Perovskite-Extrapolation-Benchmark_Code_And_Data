# Data dictionary

The primary source dataset is **not redistributed here**. It is the published HOIP dataset of
Kim, Huan, Krishnan and Ramprasad, *Scientific Data* **4** (2017) 170057 — reference [47] in the
manuscript. `src/00_fetch_source_data.sh` downloads it into `raw/`. Please cite the original paper.

The files below are derived products, regenerated by stages 01–04 of the pipeline.

| File | Rows | Produced by | Contents |
|---|---|---|---|
| `hoip_structures.csv` | 1,346 | `01_parse_structures.py` | Per-structure lattice parameters (a, b, c, α, β, γ), cell volume, atom counts, element composition, named organic A-site cation, B-site metal, halide |
| `hoip_master.csv` | 1,346 | `02_assemble_dataset.py` | The above merged with the tabulated properties: `Eg_GGA`, `Eg_HSE`, `dEg` (= `Eg_HSE − Eg_GGA`), unit-cell volume, density, atomisation energy, relative polymorph energies, electronic and ionic dielectric constants, refractive index, and the `composition` grouping key |
| `hoip_features.csv` | 1,346 | `04_protocol_audit.py` | The full feature matrix actually presented to the models: the COMP, LLM, PHYS and STRUCT blocks defined in `src/features.py`, plus the GGA rung |
| `llm_radii_validation.csv` | 16 | `03_validate_llm_descriptors.py` | Elicited A-site effective radius per cation beside the two independent published tabulations, for the memorisation control of Section 3.6 |

## Key columns

| Column | Unit | Meaning |
|---|---|---|
| `Eg_GGA` | eV | Band gap at the GGA (PBE) level — the low-fidelity rung |
| `Eg_HSE` | eV | Band gap at the HSE06 level (no spin–orbit coupling) — the prediction target |
| `dEg` | eV | `Eg_HSE − Eg_GGA`; the residual learned by the Δ formulation |
| `composition` | — | `A_cation`–`B`–`X` grouping key; 192 unique values, the grouping variable for the composition-grouped protocol |
| `A_cation` | — | Named organic A-site cation (16 values) |
| `B` | — | Group-IV B-site metal: Ge, Sn or Pb |
| `X` | — | Halide: F, Cl, Br or I |

## Units and conventions

Energies are in eV, lengths in Å, cell volumes in Å³, and elicited A-site radii in pm. The target is
the HSE06 *computational reference* gap, not an experimentally measured optical gap; see Section 2.1
of the manuscript.
